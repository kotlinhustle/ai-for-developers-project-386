# Главная страница — витрина сервиса для клиентов

Первая фича — главная страница «Календаря звонков». Решили: главная — это публичная витрина платформы, нацеленная на клиента, с одним CTA «Записаться на звонок», ведущим на страницу записи. Отдельного фаннела для организаторов (регистрация, создание календаря) и блоков FAQ / отзывы / тарифы на главной нет.

Причина: требование — «рассказывать про сервис и вести на страницу записи»; лишние ветки раздувают первую фичу. Пересмотрим, когда появится продуктовая необходимость привлекать организаторов или добавлять маркетинговые блоки.
