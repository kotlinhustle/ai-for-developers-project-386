# Календарь звонков

Сервис для бронирования звонков: организаторы публикуют свой календарь,
клиенты записываются на звонки. Этот глоссарий фиксирует язык продукта.

## Язык

**Организатор**:
Пользователь сервиса, который настраивает календарь и принимает звонки.
_Избегать_: владелец, хост, эксперт, специалист

**Клиент**:
Посетитель, который бронирует звонок у организатора.
_Избегать_: гость, пользователь, заказчик

**Главная страница**:
Публичная витрина сервиса, которая рассказывает о продукте и ведёт к записи.
_Избегать_: лендинг, домашняя страница, index

**Страница записи**:
Страница, на которой клиент бронирует звонок у организатора.
_Избегать_: страница бронирования, booking

**Слот**:
Интервал времени, который организатор открывает для записи на звонок.
_Избегать_: окно, таймслот, время

**Запись на звонок**:
Подтверждённая договорённость о звонке между клиентом и организатором в выбранном слоте.
_Избегать_: бронь, бронирование, встреча
